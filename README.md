One funny line of text, at most 200 characters, written by a small deterministic program for make.fun's "One Line, One Laugh" bounty — an AI judge compares entries two at a time and the funniest lines share the $2 reward pool.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` and prints exactly that one line to stdout. Same output on every run, standard library only.
